배차 · 식단표 사용법

대진여객 시내버스 — 딱 세 가지만 알면 됩니다

1. 앱 열기

  1. 휴대폰 브라우저에서 주소를 엽니다.
  2. 화면을 홈 화면에 추가 하면 앱처럼 한 번에 열립니다.
앱 열기

2. 아래 버튼 세 개

  • 🚌 내 배차 — 내 오늘 배차가 맨 위에 큼직하게 나옵니다.
  • 🔎 전체 조회 — 다른 기사님 배차를 찾아볼 때 씁니다.
  • 🍚 주간 식단표 — 이번 주 점심·저녁 메뉴입니다.

3. 조회하는 순서

  1. 날짜를 누릅니다.
  2. 노선을 누릅니다.
  3. 오전 / 오후를 고릅니다.
  4. 이름을 누르면 차량번호와 시각이 크게 펼쳐집니다.

내 배차 화면 맨 위의 이름을 눌러도 다른 기사님 배차를 볼 수 있습니다.

4. 화면에 뜨는 표시

오전 오후 순번 3 오늘 휴무 예비 ≈
  • 휴무(빨강) — 그날은 배차가 없습니다.
  • 예비 — 예비 차량으로 대기하는 날입니다.
  • 순번 — 그 차량에서 몇 번째로 운행하는지입니다.
  • ≈ — 표에 분만 적혀 있어 앞 시각의 시(時)를 이어 붙인 시각입니다.

5. 알아 두실 점

  • 배차표는 카페 공지가 올라오면 자동으로 새로 반영됩니다.
  • 인터넷이 잠깐 끊겨도 마지막으로 본 화면은 열립니다.
