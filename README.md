# 대진여객 배차 — 휴대폰 웹 앱

㈜대진여객 시내버스 배차표를 휴대폰에서 바로 보는 앱입니다.
브라우저로 열고 **홈 화면에 추가**하면 일반 앱처럼 전체 화면으로 열립니다.

- 주소: https://pbsjjj0318-stack.github.io/baeccha/
- 저장소: https://github.com/pbsjjj0318-stack/baeccha

## 화면

1. **내 배차** — 오늘 배차를 맨 위에 크게, 그 아래 이번 주·다음 주 내 배차 카드.
   위쪽 이름(기본 `박병수`)을 누르면 다른 기사님 이름으로 바꿔 볼 수 있습니다.
2. **조회** — 날짜 → 노선 → 오전/오후 → 이름 순서로 찾습니다.
   이름을 누르면 차량번호와 회차 시각이 더 크게 펼쳐집니다.

## 데이터

`data/YYYY-MM-DD.json` — 날짜별 배차표. `data/index.json` 이 날짜 목록입니다.
`data/app-config.json` 이 기본 이름과 이름 가림 설정을 담습니다.

원본은 워크스페이스의 `data/baeccha/` 에 있고, 이 저장소의 `data/` 는 `build_data.py` 가
만든 **배포용 사본**입니다. 둘을 직접 손으로 맞추지 말고 아래 `sync.sh` 를 쓰세요.

## 갱신 방법

```sh
sh sync.sh /workspace
```

이 스크립트가 하는 일:

1. `build_data.py` 로 `data/baeccha/*.json` → `data/*.json` 변환 (필요 없는 출처·판독 메모 제거)
2. 이름 가림 규칙 적용 (`config.json` 의 `nameMode`)
3. 바뀐 것이 있으면 commit 후 `main` 에 push → GitHub Pages 자동 배포

## 이름 가림 (`config.json`)

```json
{ "nameMode": "mask", "selfName": "박병수" }
```

- `mask` — **동료 기사님 이름은 가운데 글자를 `*` 로** (`강민구` → `강*구`, `김성훈1` → `김*훈1`).
  `selfName`(박병수)은 그대로 둡니다.
- `full` — 실명 그대로 (가림 없음)
- `self` — 본인 배차 줄만 남기고 다른 기사 이름은 지움

이 저장소는 공개 저장소이므로, `mask` 를 기본으로 둡니다. 전화번호·계정·카페 정보 같은
개인정보는 어떤 파일에도 넣지 않습니다. 배차표의 기사 이름·차량번호·시각만 들어 있습니다.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 화면 뼈대 |
| `app.css` | 화면 스타일 (큰 글씨, 흰 바탕, 파란 강조) |
| `app.js` | 조회 로직 (외부 라이브러리 없음) |
| `manifest.json` | 홈 화면 앱 설정 (이름·아이콘·standalone) |
| `sw.js` | 오프라인에서도 열리게 하는 최소 캐시 (네트워크 우선) |
| `icons/` | 앱 아이콘 (PNG·SVG) |
| `build_data.py` | 배포용 데이터 만들기 |
| `sync.sh` | 데이터 갱신 + commit + push |
| `tools/make_icons.py` | 아이콘 다시 만들기 |

## 배차표 읽기 규칙

- 회차 칸은 시가 바뀔 때만 `시/분`, 같은 시가 이어지면 분만 적혀 있습니다.
  분만 적힌 칸은 위 회차의 시를 이어받아 복원했고, 화면에 `≈` 로 표시합니다.
- 교대 경계는 표의 굵은 세로선: 189-1은 3회/4회 사이, 115-1·129-1은 2회/3회 사이.
  189·187은 표에 구분선이 없어 전체 회차를 보여줍니다.
- 이름이 비어 있는 줄(115-1의 `일신` 등)은 이름 없이 차량·시각만 표시합니다.
- 판독이 불확실한 이름은 `?` 를 붙입니다.
